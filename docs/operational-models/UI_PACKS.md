# Package reusable presentation

A UI pack is reusable presentation configuration within an App's model/package contract. It does not create a separate distribution authority or permission system.

Carry declared composite types, supported regions, field presentation, extension assets, and query/operation dependencies together. Namespaced package keys avoid accidental collision. The installed active definition must retain the requirements the presentation relies on.

Do not ship arbitrary executable snippets inside configuration. Declarative composition resolves to registered primitives; iframe assets and reviewed code plugins use their explicit boundaries.

On installation and upgrade, validate keys, source shapes, dependencies, accessible records, unavailable states, and action outcomes. Pause/removal must withdraw the applicable package capabilities. Use the reference package and [extension contract](../platform/extension-contract-v1.md) as implementation patterns.
