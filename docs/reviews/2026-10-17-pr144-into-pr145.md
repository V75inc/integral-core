5. **Card columns shifted between records.** Derive group positions from the declared fields rather than only populated rows; a regression preserves the empty first column and the second/trailing groups.

Markdown uses a multiline draft; the Strict Mode mount guard is reset during effect setup so successful saves close and re-enable the editor. Strict Mode regression covers commit only on blur and completion.
