# Integral's canonical mark

The approved mark is the frameless split square. Preserve its two-path geometry and the absence of an enclosing frame. This directory retains the canonical masters, geometry, generator, and size inspection assets; the dated path remains for source compatibility.

`integral-logo.svg` and `integral-logo-white.svg` are the masters. `geometry.json` is the implementation geometry. Frontend exports and favicon assets derive from the approved shape. Use raw SVG imports for frontend tests rather than Node filesystem imports.

The auth hero uses a stationary outline of the mark. Brand geometry is separate from page decoration or animation. See [geometry notes](SPLIT-SQUARE.md).
