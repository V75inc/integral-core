# ADR 003 — One resident per active binding

**Status:** Accepted architecture.

## Decision

Use a singular resident mind per active harness binding, faceted by principal and scope. Default to Integral AI through Pydantic AI; use it as the only resident harness. Core supplies the authority and execution perimeter.

## Consequences

External agents use MCP. The retired A2A peer fabric is absent and must not be revived through discovery/delegation aliases. Agentive boot is always on. See [resident harness](../../product/RESIDENT_HARNESS.md).

This edition removes superseded implementation narratives while preserving the decision boundary. Historical discussion remains in Git; current release evidence belongs in the qualification record.
