# ADR 004 — Coherent domain Apps and reusable capabilities

**Status:** Proposed composition direction; not a completed suite reorganization.

## Decision

Keep a domain's content and workflows in a coherent App. Separate reusable routines from content-owning domain Apps where the package/lifecycle contract supports that choice. Express cadence through reviewed resident scheduling rather than another always-on domain agent.

## Consequences

This direction does not prove every proposed utility bundle or domain migration exists. Dependencies, scheduled authority, and ownership must be validated in each concrete implementation. See [package architecture](../app-bundles-v1.md).

This edition removes superseded implementation narratives while preserving the decision boundary. Historical discussion remains in Git; current release evidence belongs in the qualification record.
