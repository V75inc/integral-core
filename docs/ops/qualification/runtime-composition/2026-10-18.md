## Implementation

- One Core engine with immutable local/hosted descriptors and explicit operation
  metadata. Limits precede ordinary human, agent, connector and system grants.
- Generic identity/session and transport adapters; stable compatibility imports,
  owner IDs, DesktopIdentity discriminator, stored profiles and recovery keys.
- Core UI consumes a protected host-session interface. One owns its native bridge,
  verified display profile and sign-in/offline return view through the overlay.
- Reusable Apache Electron host source/tests/notices move to One. Core's legacy
  Electron product/workflow are removed; its local launcher, storage and recovery
  primitives remain supported.
- Unknown operations fail closed, including when the private audit-recursion
  keyword is supplied. The audit test now exercises the actual `policy.deny`
  action rather than relying on an arbitrary unknown action bypass.

### Native Windows private-directory correction

One's native runtime gate exposed `initdb` rejecting the managed PostgreSQL
folder on an elevated Windows runner. A synthetic differential probe failed
with the original Python `0700` directory and passed with an explicit token-user
SID grant. The production helper now applies a protected Windows DACL for the
current user, SYSTEM and Administrators before writing runtime secrets or
initializing PostgreSQL. It preserves owner-only POSIX modes. No Users/Everyone
grant, elevation requirement, database path change or key rotation is introduced.
The same protection covers installation and restore quarantine directories.
ACL failures propagate and stop startup.

The actual native implementation initialized PostgreSQL successfully in a fresh
Windows runner directory (One investigation run `39177397298`). Three local
regressions cover POSIX mode, native Windows delegation and fail-closed errors.
This targeted native probe is not the full One runtime/installer qualification;
that matrix must pass using the rebuilt paired artifact.

Follow-up native run `39177802964` used the exact helper/ACL source, reached
managed database readiness and stopped cleanly. Temporary investigation files
are excluded from the final One candidate. Ninety-three focused runtime/privacy
and frontend-policy tests pass; the full backend gate is recorded separately.
