## Combined behavior

- Native transaction reads replace the Core compatibility shim; Admin inventory
  uses canonical workspace registries and resolves principal-backed owner names.
- Invited-member track listings retain workspace admission and resource grants.
- Successful database observation calls produce no routine operation logs;
  error logs and metrics remain available.
- Home and Admin layouts, responsive icon send, shared attachments/dictation/
  mentions, immediate Home/Enhance submission, floating welcome acknowledgement,
  suggestion menu placement, search spacing, profile ordering and consolidated
  profile routing are included.
- User messages use muted slate and an accent along the top; assistant answers
  have plain text. Error surfaces use red text and outlines.
- Ordinary lists/details/pickers and Enhance prompts omit internal identifiers;
  identifiers remain available in technical diagnostics and evidence artifacts.
- Passive approval reconciliation cannot start a provider continuation. Explicit
  actions retain continuation and deduplicate receipts across polling races.
- Native turn budget defaults to 1,200,000 tokens. The budget audit and bounded
  retrieval constraints remain documented; increasing the cap does not remove
  the need to control context growth.

## Bounds and qualification limits

The graph capture has a cooperative three-second work deadline. Under concurrent
full-suite load, a broad live-agent capture exceeded it; the model recovered
through bounded record reads and answered correctly. A narrower hotel-root
capture returned authorized recorded detail with `complete: false` and an
explicit timeout stop reason. Workspace-wide recorded detail is intentionally
rejected with a request to narrow the root. This is bounded partial coverage,
not evidence of complete graph capture or production latency. A focused `REFERENCES`-only
hotel capture subsequently completed in **1.44 seconds**, with all three
expected nodes and no stop reasons; see [focused capture](narrow-graph.json).
No deadline or permission boundary was relaxed to make a test pass.

Optional external infrastructure and slow/benchmark lanes skipped by the normal
suite are not qualified by those skips. Existing ESLint warnings remain a
tracked backlog; there were no lint errors. No finite test suite establishes
that every possible defect is absent.
