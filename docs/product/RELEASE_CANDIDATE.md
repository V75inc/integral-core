# Release candidate

The former release-candidate table was a historical sprint snapshot. It named
an old branch and marked broad acceptance criteria as done without an immutable
candidate, artifact digests, deployment topology, or complete gate results.

Use [CORE_ACCEPTANCE_LEDGER.md](CORE_ACCEPTANCE_LEDGER.md) for every future
candidate. It is the authoritative evidence record and keeps unrun, skipped,
partial, and blocked work visible.

The historical public-developer work-package snapshot remains available in
[SPRINT_STATUS.md](SPRINT_STATUS.md). It is not a release declaration.
