# Resident compatibility configuration

This directory contains the jvagent-compatible resident definition and resources. Integral's default resident uses the native Pydantic AI binding; this configuration is a selectable compatibility path.

Core owns authenticated scope, capabilities, policy, staged effects, transcripts, and observations around either harness. Do not run this definition as evidence of another authority plane or a peer-agent fleet. External participants connect through MCP.

Compatibility bootstrap uses the configured jvagent update mode. Source, merge, and run modes have different handling of existing action properties; choose deliberately rather than relying on a stale local graph. The separate jvagent embed HTTP surface is disabled by default.

Keep skill and capability declarations aligned with the runtime catalog. Standard disk skill files have their own format; agent configuration keys do not become SKILL.md vendor fields. Test actual routing, scope, current permissions, cancellation, review, and result readback when changing the binding.
