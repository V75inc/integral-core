# Local Integral distro (scaffold)

Generated by `integral init`. Apps live in `integral-apps/`. Each directory
name equals `package.slug`.

The TCS App package lives outside this distro:

```text
/Users/tharickjairam/jvsproject/agents/tcs-ai/integral-apps/tcs-app
```

Start Core from the `integral-core` checkout:

```bash
cd /Users/tharickjairam/jvsproject/integral-core
backend/.venv/bin/integral up --port 9006 \
  --apps /Users/tharickjairam/jvsproject/agents/tcs-ai/integral-apps
```

Then install / open **TCS App** (`tcs-app`) in the workspace.

```bash
backend/.venv/bin/integral status
backend/.venv/bin/integral logs --service api --lines 200
backend/.venv/bin/integral stop
```
